PrivAgent

Privacy-First AI Browser Agent

An intelligent browser agent that understands web pages, detects sensitive information locally, redacts PII before any network transmission, and executes AI-driven browser actions — all while keeping your personal data private.

How It Works

1
🔍

DOM Analysis

Extracts page structure, form fields, buttons, and interactive elements from the DOM

2
🛡️

PII Detection

Locally detects emails, phone numbers, Aadhaar, passwords, credit cards, and faces

3
🔒

Redaction

Replaces all sensitive values with semantic placeholders like [REDACTED_EMAIL]

4
📡

Safe Transmission

Sends only sanitized metadata to the backend — never raw PII

5
🤖

AI Analysis

LLM analyzes the sanitized page context and generates structured JSON actions

6
⚡

Browser Action

Extension executes click, fill, and scroll actions locally in the browser
