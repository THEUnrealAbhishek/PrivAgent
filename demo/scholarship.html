🛡️ What PrivAgent Does Here

When you click Start PrivAgent in the extension:

  1. Detects sensitive fields (email, phone, Aadhaar, password, PAN)
  2. Redacts all PII values with [REDACTED_*] placeholders
  3. Sends only sanitized metadata to the backend
  4. Receives structured JSON actions
  5. Executes actions locally in the browser
